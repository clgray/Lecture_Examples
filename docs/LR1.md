# Лабораторная работа №1

## Какая задача решается
В предоставленном коде реализован поведенческий паттерн **«Наблюдатель» (Observer)** на языке C#. Задача этого паттерна — создать механизм связи «один-ко-многим» между объектами. Когда один объект (источник данных, в коде это `ConcreteObservable`) изменяет свое состояние, он должен автоматически уведомить об этом все зависящие от него объекты (наблюдателей), не зная деталей их реализации.

## Как решается задача
1. **Хранение подписчиков**: В классе `ConcreteObservable` есть приватный список `List<IObserver> Observers`. В конструкторе он инициализируется пустым списком. Для управления этим списком предусмотрены методы `AddObserver` и `RemoveObserver`.
2. **Механизм оповещения**: В коде используется современный механизм C# — события. Объявлен делегат `Update`, который принимает строку `s`. В классе `ConcreteObservable` объявлено событие `public event Update OnUpdate`. Метод `NotifyObservers` вызывает это событие (`OnUpdate?.Invoke(s)`). Ранее закомментированный код (цикл `foreach` по списку `Observers`) показывает классический вариант паттерна, но теперь используется событие, что позволяет избежать ручного перебора списка и снижает связанность.
3. **Асинхронный запуск**: Метод `Go()` создает новый поток (`new Thread(Run).Start()`). Внутри метода `Run()` запускается цикл `foreach (string s in simulator)`. На каждой итерации:
   - текущее значение выводится в консоль;
   - обновляется публичное свойство `SubjectState`;
   - вызывается `NotifyObservers(s)`, что оповещает всех, кто подписан на событие `OnUpdate`;
   - поток засыпает на 5000 мс (`Thread.Sleep(speed)`), имитируя длительную обработку или потоковую передачу данных.
4. **Роль диаграммы**: На диаграмме классов (PlantUML) отражено, что делегат `Update` представлен как отдельный класс (с методом `Invoke`), так как в C# делегат — это тип данных. Связь `ConcreteObservable ..> Update` показывает, что класс использует этот тип для события, а `ConcreteObservable *-- Simulator` указывает на композицию с источником данных `Simulator`.
